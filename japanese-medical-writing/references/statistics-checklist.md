# 統計の記述セルフチェック

方法・結果・考察の統計の書き方で、査読で繰り返し指摘される点。数値そのものは著者の解析結果だけを使う（ここは「書き方」の点検であり、解析をやり直す場所ではない）。

## 方法に書くこと

- [ ] 主要評価項目と副次評価項目を区別し、事前に決めていたか（試験登録・プロトコルと一致するか）を書いた
- [ ] 検証的解析と探索的解析（事後解析）を区別した
- [ ] サンプルサイズの根拠（想定した効果量・α・検出力）を書いた。根拠がなければその旨
- [ ] 各評価項目に使った検定・モデル名、両側か片側か、有意水準
- [ ] 調整した共変量と、その選び方
- [ ] 多重比較の扱い（どの比較の範囲で補正したか／しなかったならその理由）
- [ ] 欠測の量と理由（群・時点ごと）と、扱い方（完全ケース解析・多重代入など）
- [ ] 外れ値の扱いと変数変換を、結果を見る前に決めていたか
- [ ] 統計ソフト名と版

## 解析単位

- [ ] 1人から複数の眼・病変・歯・来院を得ている場合、独立として扱っていない（扱うならその理由と、クラスタを考慮した方法）
- [ ] 解析単位（患者・病変・画像など）を数値ごとに明記した

## 結果の書き方

- [ ] 効果量と信頼区間を示した（p値だけにしない）
- [ ] 二値アウトカムは各群の事象数/分母、絶対指標（リスク差）と相対指標（リスク比・オッズ比）を区別して示した
- [ ] 対象者の流れ（適格→登録→割付→介入→追跡→解析）の人数が本文・表・図・抄録で一致している
- [ ] 解析対象集団（ITT・PP 等）を数値ごとに明記した

## よくある誤った推論（書かない）

- 事後検出力（observed power）を計算して「検出力不足だったので差が出なかった」と書く
- 「A群では有意、B群では有意でない」ことを、A群とB群の差（交互作用）の根拠にする。サブグループ差は交互作用の検定や推定で示す
- RCT で患者背景の群間差を有意差検定して、ランダム化の成否を判断する
- 有意差なしを「差がない」「同等」「無効」と書く
- p = 0.06 などを「有意傾向」と呼び、有意差と同じように解釈する
- 信頼区間が重なることを「差がない」根拠にする（重なっていても差が有意なことはある）
- 欠測が完全にランダムだという検定結果だけを根拠に、欠測の影響を否定する

## 予測モデル・AI を使う研究

- [ ] 前処理・特徴量選択を交差検証の内側で行った（データ漏洩がない）
- [ ] 識別能（AUC など）だけでなく較正（calibration）も示した
- [ ] 内部検証か外部検証かを明記した
- [ ] TRIPOD+AI／STARD-AI 等の該当ガイドラインに沿った
