# 論文種別ごとの構成

字数・図表数はあくまで和文誌でよく見る目安。**必ず投稿規定の値を優先**する（規定が取れなければ、その旨を未解決リストに書く）。

## 原著論文（IMRAD）

| 節 | 書くこと | 注意 |
|---|---|---|
| 表題 | 対象・介入/曝露・アウトカム・デザインが分かる | 「〜の検討」だけで終わらせない。デザインを入れる（例：「〜：後ろ向きコホート研究」） |
| 抄録 | 目的／方法／結果／結論（構造化） | 本文にない数値を入れない。結論は結果から言える範囲 |
| 緒言（はじめに） | ①既知のこと ②未解明のこと（ギャップ） ③本研究の目的 | 最後の段落を目的1文で締める。教科書的な一般論を長く書かない |
| 対象と方法 | デザイン、セッティング・期間、対象（選択/除外基準）、介入/曝露、アウトカム定義、サンプルサイズ、統計解析、倫理 | 第三者が再現できる粒度。統計ソフトと版、有意水準、欠測の扱い |
| 結果 | 対象者の流れ→背景→主要アウトカム→副次→有害事象 | 解釈を書かない。表と本文の重複は要点のみ |
| 考察 | ①主要な知見の要約 ②先行研究との比較 ③機序・解釈 ④臨床的意義 ⑤限界 ⑥今後 | 結果を繰り返さない。限界は下の「限界の書き方」に従う |
| 結語 | 2〜3文 | 結果で示した範囲を超えない |
| 謝辞・COI・資金 | | `ethics-coi.md` |
| 文献 | | `citations.md` |

### 書く順番

本文（方法→結果→考察→緒言）を先に固め、**抄録と表題は最後**に書く。抄録は本文の要約であり、本文にない解釈や数値を入れない。

### 方法と結果の対応

- 結果に出てくる解析は、すべて方法に書かれていること（方法にない解析が結果に突然出てこない）。
- 方法は「理想的にはこうすべき」ではなく「実際に行ったこと」を書く。結果に合わせて方法を後から作文しない。
- 解析対象集団・除外・欠測の扱い・多重比較の扱いが、方法と結果で一致していること。

### 限界の書き方

定型の「単施設・後ろ向き・症例数が少ない」で済ませない。各限界について次を書く。
1. 何が限界か（例：入院例のみを対象とした選択バイアス）
2. 結果がどちらの方向にずれうるか（過大評価／過小評価、根拠があれば）
3. どの程度結論に影響するか、どう補ったか（感度分析など）

設計・対象・測定・追跡・検証・一般化可能性のどれに当たるかを意識し、結論への影響が大きい順に並べる。「どう補ったか」は実際に行ったこと（台帳に根拠があるもの）だけを書く。「〜により影響は最小限と考えられる」のような根拠のない緩和文を足さない。

### 表題の注意

本文が支持しない新規性・因果・デザイン・対象集団を表題に入れない（例：観察研究で「〜は〜を改善する」）。

## 症例報告（CARE準拠）

| 節 | 書くこと |
|---|---|
| 表題 | 「〜を呈した〜の1例」が和文の定型だが、「○○の一例」を避けるよう定める誌もある（例：日本小児科学会雑誌）。字数制限・副題の可否も誌規定で確認。新規性が伝わる語を入れる |
| 抄録 | 症例の要点と教訓 |
| はじめに | なぜ報告する価値があるか（稀少性・診断上の教訓・新しい治療反応）を2〜3文 |
| 症例 | 患者情報（年齢・性別、主訴、既往・家族歴・生活歴は関連分のみ）→現病歴→身体所見→検査所見→臨床経過（時系列） | 日付は「X年Y月」「第Z病日」。施設名・地名・職業の詳細は特定につながるなら省く |
| 考察 | 文献的考察（類似報告との比較）、診断・治療の根拠、限界 |
| 結語 | 教訓1〜2点 |
| 同意 | 本人（不能なら代諾者）から論文発表の文書同意を得た旨 |

時系列が長い症例は経過表（日付・所見・治療）を作ると読みやすい。

## 症例集積（ケースシリーズ）

複数症例をまとめて記述・分析する。いわゆる症例報告と違い、倫理指針上の「研究」に当たりうるので、倫理審査の要否を著者に確認する（`japanese-sources.md` 2節）。
- 構成は原著（IMRAD）に近い：対象の選び方（期間・選択基準・連続症例か）、収集した項目、記述統計
- 外科系では PROCESS ガイドライン、外科症例報告では SCARE ガイドラインを求める誌がある（`guidelines.md`）
- 症例数が少ない記述研究であることを限界に書き、比較・因果を主張しない

## 短報・速報

原著を圧縮した形。緒言と考察を短くし、結果を中心に。図表は1〜2点が多い。

## 総説

- ナラティブ総説：見出しは論点ごとに自由。文献検索の範囲（データベース・期間・キーワード）を冒頭に書くと信頼性が上がる。
- 系統的レビュー：PRISMA 2020 に従う。検索式・選択過程・バイアス評価を必ず記載。

## 学会抄録

- 字数制限が厳しい（数百字程度が多い）。定型：【目的】【方法】【結果】【結語】、症例は【症例】【経過】【考察】。
- 字数は**全角換算か文字数か**、表題・著者名を含むかを規定で確認する。
- 結果に具体的数値を入れる（「有意に改善した」だけにしない）。数値は手持ちデータのみ。
- 字数カウント：`python3 scripts/lint_ja.py --count abstract.md`

## 学会発表（スライド・ポスター）

- 多くの学会が、発表スライドの冒頭（ポスターでは所定の位置）で COI の開示を求めている（日本医学会 COI 管理ガイドラインでも学会発表時の開示を定めている）。様式は学会の指定に従う。
- 抄録・発表でも倫理審査・同意の扱いを記載するよう求める学会がある。
- 患者画像・動画は論文と同じ基準で匿名化し、同意の範囲を確認する。
- スライド・ポスターの構成そのものはこのスキルの対象外だが、表記・数値・個人情報の点検はそのまま使える。

## 研究計画書の背景・目的

原著の緒言に近いが、研究の必要性（なぜ今、なぜこのデザインか）を厚く書く。仮説を明示する。
