# 文献の書き方と検証

## 1. 検証が先、整形は後

文献リストに載せる前に、各文献の実在と書誌情報を確認する。標準はユーザーが提示した原典（PDF・文献管理ソフトの書き出し）での照合。Web 照合はユーザーが許可した場合のみで、送るのは公開文献の DOI/PMID・題名など公開情報だけにする。照合先：
- 英文：PubMed（PMID）、DOI（https://doi.org/）、出版社ページ
- 和文：医中誌Web、J-STAGE、CiNii Research、DOI

確認した項目：著者名（全員の綴り）・題名・誌名・発行年・巻（号）・頁・DOI。

「確認した」と言えるのは、原典（少なくとも該当部分の本文）を開いて確かめた場合だけ。次は手がかりにはなるが確認にはならない：検索結果のスニペット、AI による要約、記憶、他の論文の文献リスト（孫引き）。台帳に確認者と確認日を残す。
**確認できない文献は載せない**。もっともらしい文献を「補う」ことはしない。本文側は `【要文献：…】` とし、未解決リストに回す。また、引用した文献が実際にその主張を支持しているか（抄録だけでなく本文で）を確認するのも著者責任である（ICMJE 2025年改訂）。

## 2. 引用番号

- 本文中は出現順に通し番号。和文誌の多くは上付き数字か `[1]`、`1)` のいずれか。誌規定に従う。
- 同じ文献は初出の番号を再使用する。
- 連続は `1–3)`、非連続は `1,4,7)` のように書く。
- `scripts/check_refs.py` が `[n]`、`n)`、`^n^`（Markdown上付き）形式の番号と文献リストの対応を確認する。

## 3. 書式（誌指定がない場合の既定：Vancouver/NLM 系）

以下は**書式を示すための架空の文献**。実在しない。

英文雑誌：
```
1) Tanaka A, Suzuki B, Sato C, et al. Effect of a fictional intervention on sample outcomes: a hypothetical cohort study. Fict J Med. 2024;12(3):101-9. doi:10.0000/example.0001
```

和文雑誌：
```
2) 架空太郎, 見本花子, 例示一郎. 架空疾患に対する仮想治療の検討. 架空医学雑誌. 2023;45(6):789-95.
```

書籍（章）：
```
3) 見本次郎. 架空症候群. 例示三郎 編. 架空内科学. 第2版. 東京: 架空出版; 2022. p.120-35.
```

ウェブ資料：
```
4) 架空省. 架空ガイドライン 2025. https://example.go.jp/guideline （参照 2026-10-01）
```

規則：
- 著者は3名（誌により6名）まで記載し、それ以上は「, 他」（和文）／「, et al.」（英文）。
- 和文誌名は誌規定に従い、医中誌の略誌名（医中誌Web 収載誌リスト）か完全誌名（完全誌名を求める誌もある）。英文誌名は NLM 略誌名（PubMed 表記）。
- 学会抄録の引用を認めない誌がある。
- 頁は誌規定に従い省略形（101-9）か完全形（101-109）。
- ウェブ資料は参照日を入れる。

## 4. 出典の役割を取り違えない

| 主張の種類 | 適した出典 | 不適切な使い方 |
|---|---|---|
| 治療効果・診断精度 | 一次研究（RCT・コホート等）、系統的レビュー | 添付文書・承認・保険収載を効果の根拠にする |
| 一般的知見・背景 | 総説・診療ガイドライン | 総説を一次データの代わりに引用する |
| 推奨・標準治療 | 診療ガイドライン（版と年を明記） | 古い版の推奨を現行として書く |
| 進行中の研究 | 試験登録（jRCT 等） | 登録情報だけで結果を引用する |

- 同じ研究（同一コホート）の学会抄録・プレプリント・本論文を、別々の研究として数えない。
- 動物実験・in vitro の結果を、臨床での効果として一般化しない。
- 出典より強い言い換えをしない（出典が「関連」なら引用文も「関連」）。

## 5. よくある誤り

- 本文で引用していない文献がリストにある／リストにない番号が本文にある → check_refs.py で検出
- 二次文献（総説）の孫引きを一次文献として引用 → 可能な限り一次文献を読んで引用
- プレプリントを査読済み論文として扱う → プレプリントと明記
- 撤回論文の引用 → Retraction Watch Database や PubMed の撤回表示で確認
- 同じ文献の重複（DOI 表記ゆれ、和文・英文の二重登録）→ DOI を小文字化・`https://doi.org/` を除いて比較
