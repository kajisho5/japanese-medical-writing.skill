# ローカル LLM で使う導入手順（Mac / Windows）

原稿や患者情報を**自分のパソコンの外に出さずに** AI を使うための手順です。パソコンに慣れていない方向けに、1つずつ書いています。

使うものは無料の2つです。

| 名前 | 役割 |
|---|---|
| **Ollama**（オラマ） | AI のモデル（頭脳）を自分のパソコンで動かすソフト |
| **OpenCode**（オープンコード） | AI に作業をさせる画面（エージェント）。このスキルを読み込んで使う |

所要時間：30分〜1時間（モデルのダウンロード時間による）

> 2026年10月時点の公式ドキュメントで確認した手順です。画面や手順が変わっていたら、各公式サイトの説明を優先してください。
> - Ollama（Windows）：https://docs.ollama.com/windows
> - Ollama（Mac）：https://docs.ollama.com/macos
> - Ollama と OpenCode の連携：https://docs.ollama.com/integrations/opencode
> - コンテキスト長：https://docs.ollama.com/context-length
> - OpenCode：https://opencode.ai/docs

---

## 0. 始める前に：パソコンの条件

| | Mac | Windows |
|---|---|---|
| OS | macOS Sonoma（14）以降 | Windows 10 22H2 以降（Home / Pro） |
| チップ・GPU | Apple シリコン（M1 以降）なら GPU を使えて速い。Intel の Mac は CPU だけで動くので遅い | NVIDIA の GPU（ドライバ 551.61 以降）や対応する AMD の GPU があると速い。なくても CPU で動くが遅い |
| 空き容量 | モデル1つで数GB〜数百GB。余裕を持って空けておく | 同左（Ollama 本体だけで 4GB 以上） |
| メモリ | 多いほど大きなモデルと長い文章を扱える | GPU のメモリ（VRAM）が多いほど有利 |

**大事なこと**：パソコンの性能が足りないと、とても遅い、または文章の質が低くなります。その場合も、このスキルの点検ツール（`scripts/`）は AI なしで使えます（`GUIDE.md` の「C. AI を使わずに使う」）。

### 「ターミナル」の開き方

この手順では、文字でパソコンに命令する画面（ターミナル）を使います。

- **Mac**：Finder →「アプリケーション」→「ユーティリティ」→「ターミナル」。または ⌘（command）＋スペースで「ターミナル」と入力して Enter。
- **Windows**：スタートボタンを右クリック →「ターミナル」または「Windows PowerShell」。またはスタートメニューで「PowerShell」と検索。

命令（コマンド）は、このガイドの灰色の枠の中の文字をコピーして、ターミナルに貼り付けて Enter を押します。

## 1. Ollama を入れる

### Mac

1. https://ollama.com/download を開き、Mac 用をダウンロードします。
2. ダウンロードした `ollama.dmg` を開き、Ollama のアイコンを「アプリケーション」フォルダにドラッグします。
3. 「アプリケーション」から Ollama を起動します。
4. 初回起動時に「コマンドラインツールのリンクを作成するか」と聞かれたら、**許可**します（ターミナルで `ollama` を使うために必要）。

### Windows

1. https://ollama.com/download を開き、Windows 用（`OllamaSetup.exe`）をダウンロードします。
2. `OllamaSetup.exe` をダブルクリックしてインストールします（管理者権限は不要）。
3. インストール後、Ollama は画面右下（タスクトレイ）で自動的に動いています。

### 確認（Mac・Windows 共通）

ターミナルを開いて、次を貼り付けて Enter：

```bash
ollama --version
```

バージョン番号が表示されれば成功です。「見つかりません」と出たら、ターミナルを一度閉じて開き直すか、パソコンを再起動してください。

---

## 2. AI のモデルをダウンロードする

1. https://ollama.com/search でモデルを探します。選ぶときの目安：
   - **日本語に対応している**（説明に Japanese / multilingual とあるもの）
   - **長い文章を扱える**（コンテキスト長が 64k 以上）
   - **自分のパソコンで動く大きさ**（モデル名の後ろの数字、例「8b」「32b」が大きいほど高性能だが、メモリが多く必要）
2. 使うモデルが決まったら、ターミナルでダウンロードします（`モデル名` の部分を選んだ名前に置き換え）。

```bash
ollama pull モデル名
```

3. ダウンロードが終わったら、動くか試します。

```bash
ollama run モデル名
```

「>>>」が出たら、日本語で「こんにちは」と送ってみます。返事が来れば成功です。終わるときは `/bye` と入力します。

> **クラウドで動くモデルに注意**：Ollama には、ダウンロードせずに使える「クラウドモデル」もあります。これを選ぶと、入力した内容は外部で処理されます。**原稿を外に出さないためには、`ollama pull` でダウンロードしたモデルを使ってください。**

---

## 3. 長い文章を扱えるように設定する（重要）

Ollama は、初期設定では一度に扱える文章の長さ（コンテキスト長）が短めです（GPU メモリが 24GB 未満なら 4k トークン）。論文やスキルの手順書を読ませるには足りないので、**64k（64000）以上**に上げます。

### いちばん簡単な方法（Mac・Windows 共通）

Ollama アプリの「設定（Settings）」を開き、**コンテキスト長（Context length）のスライダーを 64k 以上**に動かします。

### 確認

モデルを動かしている状態で、別のターミナルを開いて：

```bash
ollama ps
```

`CONTEXT` の欄が設定した値になっていれば OK です。`PROCESSOR` の欄に CPU と出ている割合が大きいと、メモリが足りずに遅くなっています。その場合は、より小さいモデルを選ぶか、コンテキスト長を少し下げます。

---

## 4. OpenCode を入れる

### Mac

ターミナルで：

```bash
curl -fsSL https://opencode.ai/install | bash
```

### Windows

1. 先に **Node.js**（無料）を入れます。https://nodejs.org/ から「LTS」と書かれた版をダウンロードしてインストールします。
2. PowerShell を開き直して：

```bash
npm install -g opencode-ai
```

> 他のインストール方法は https://opencode.ai/docs を参照してください。

---

## 5. Ollama と OpenCode をつなぐ

ターミナルで次を実行します（Mac・Windows 共通）。

```bash
ollama launch opencode
```

使うモデルを聞かれたら、手順2でダウンロードしたモデルを選びます。OpenCode の画面が開けば成功です。

---

## 6. このスキルを入れる

1. GitHub のこのリポジトリのページで、緑色の「Code」→「Download ZIP」を押してダウンロードし、展開します。
2. 展開したフォルダの中の **`japanese-medical-writing`** フォルダを、次の場所にコピーします。

| | コピー先 |
|---|---|
| Mac | ホームフォルダの中の `.agents/skills/` |
| Windows | `C:\Users\あなたのユーザー名\.agents\skills\` |

`.agents` のように「.」で始まるフォルダは、普段は隠れています。ターミナルで作ってコピーするのが確実です（ダウンロードしたフォルダの場所に移動してから実行）。

**Mac**

```bash
mkdir -p ~/.agents/skills
cp -r japanese-medical-writing ~/.agents/skills/
```

**Windows（PowerShell）**

```powershell
New-Item -ItemType Directory -Force "$HOME\.agents\skills"
Copy-Item -Recurse japanese-medical-writing "$HOME\.agents\skills\"
```

3. OpenCode を一度閉じて、もう一度 `ollama launch opencode` で起動します。

---

## 7. 使ってみる

### 作業用フォルダを用意する

デスクトップなどに「論文作業」のようなフォルダを作り、原稿や経過メモ（匿名化したもの）をそこに置きます。ターミナルでそのフォルダに移動してから OpenCode を起動すると、AI がそのフォルダのファイルを読めます。

```bash
cd ~/Desktop/論文作業
ollama launch opencode
```

（Windows では `cd $HOME\Desktop\論文作業`）

### 最初の一言

まずは架空の症例で試します。

```
ローカルLLMで動かしています。架空の症例で、症例報告の練習原稿を作ってください。
70歳代男性、発熱と腰痛で入院、血液培養で黄色ブドウ球菌、MRIでL3/4化膿性脊椎炎、
セファゾリン6週間で改善。投稿先は未定です。
```

「ローカルLLMで動かしています」と最初に伝えると、スキルは施設規程の確認を前提に作業します。

### スキルが使われているか分からないとき

「japanese-medical-writing スキルを使って」と頼んでください。それでも使われない場合は、手順6のコピー先とフォルダ名（`japanese-medical-writing` の中に `SKILL.md` があるか）を確認します。

---

## 8. 本当に外に出ていないか確かめる

- 使っているモデルが `ollama pull` でダウンロードしたものか（`ollama list` で一覧が出ます）
- OpenCode でクラウドのモデル（Claude・GPT・Gemini など）を選んでいないか
- 心配なら、パソコンを**インターネットから切断した状態**で動くか試します。動けば、会話は手元で処理されています（モデルのダウンロードと各ソフトの更新にはインターネットが必要です）

---

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| `ollama` が見つからないと言われる | ターミナルを開き直す。Mac は初回起動時のリンク作成を許可したか確認。Windows は再起動 |
| 返事がとても遅い | モデルが大きすぎる。小さいモデル（数字の小さいもの）を試す。`ollama ps` で CPU の割合を確認 |
| 長い原稿の途中を忘れる・手順を守らない | コンテキスト長が足りない（手順3）。または、モデルの性能が足りない |
| 日本語がおかしい | 日本語に強いモデルに変える |
| スキルが使われない | 手順6のコピー先を確認し、OpenCode を再起動 |
| Windows で文字が四角になる | ターミナルのフォントを変更する |

ローカルのモデルは、クラウドの大きな AI より文章の質が落ちることがあります。その場合でも、**下書きの骨子づくり・表記の点検・未解決リストの作成**には十分役立ちます。点検ツールは AI の性能に関係なく同じ結果を出します。
